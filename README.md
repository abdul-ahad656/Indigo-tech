# Indigo Tech Solutions — Company Website

Premium animated React/Vite company website for Indigo Tech Solutions.

## Sections
- Hero / company positioning
- Company overview
- Animated service cards
- Logistics + BPO capabilities
- Technology-in-motion video section
- Leadership team
- Client feedback placeholders
- Contact CTA

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Netlify
The repository includes `netlify.toml` with:
- build command: direct Node execution of Vite (helps avoid `vite: Permission denied`)
- publish directory: `dist`
- Node 20

## Assets
- `public/assets/indigo-logo.jpg` — uploaded company logo
- `public/assets/company-banner.png` — uploaded banner
- `public/assets/team/` — add leadership photos
- `public/videos/tech-showreel.mp4` — add an optional tech/BPO video

## Important
The website content is company-facing and does not present a personal employment timeline.
The operational capabilities are presented as Indigo Tech Solutions services.
Client feedback cards are clearly sample placeholders and should be replaced with verified feedback.
